# Onboarding de Cobro por Cuenta Ajena · prototipo (Hyper)

Demo navegable del onboarding de empresas al servicio Cobro por Cuenta Ajena: 8 etapas, 3 vistas (Portal, Backoffice y Consola) y 6 agentes de IA simulados.

**Probarla:** https://astral910.github.io/hyper-banrural-cca-demo/

- Cambia de rol con «Ver como».
- «Presentación» recorre las 8 etapas sola.
- El código OTP de la demo es **482913**.

**Es un prototipo:**
- todos los datos son ficticios;
- los agentes, las integraciones y la firma son simulados;
- no es un sitio oficial de Banrural.

Lo que se escribe queda solo en el navegador de quien la prueba, y «Reiniciar» la deja como al inicio.

`index.html` es la demo construida de la rama `completo` del repo privado `Astral910/hyper-banrural-cca`, commit `700b964`. El código fuente, el análisis y la evidencia están allá.
